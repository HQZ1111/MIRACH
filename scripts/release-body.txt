Mirach v0.1.0 - 多 Agent 智能体系统

多 Agent 协作 · 多工作环境 · 自进化 harness。

下载方法：把 Mirach-portable.7z.001 ~ .002 两个分卷下载到同一个文件夹，
用 7-Zip（或 Windows 11 资源管理器）右键解压任一分卷即可得到完整目录（约 1.3GB）。

启动：双击 Mirach.exe（Windows 10/11，一般自带 WebView2）。
首次使用：设置 → 模型配置，填入你自己的 API Base URL 与 API Key
（软件不内置任何密钥，数据只保存在本机）。

目录里 runtime/ 是便携 Node.js + dsh 引擎 + 桥接服务，勿删。
会话数据保存在 C:\Users\<你>\.hermes\dsh-sessions\。
